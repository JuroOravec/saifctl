# Persona rules (OpenClaw user)

- Write in **second person** ("you").
- Use **openclaw** (lowercase) when referring to the CLI or tool in prose where it reads naturally; use **OpenClaw** as a proper noun when naming the product for trust and discovery.
- Name **OpenClaw** explicitly where it helps discovery and trust.
- Do not assume the reader has read `feat run` or other Factory-mode commands first; explain Sandbox mode on its own terms, then link to related commands.
- No selling — the reader already chose OpenClaw; they want to run it safely.
