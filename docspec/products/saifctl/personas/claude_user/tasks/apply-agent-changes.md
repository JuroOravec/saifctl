# Task: apply agent changes to working tree

The reader has run `saifctl sandbox` successfully and wants to apply the agent's output (git changes from inside the container) to their real project using `--extract`.

Success: they understand what `--extract` does, can run it, and know the `--extract-include` / `--extract-exclude` flags for surgical application.
