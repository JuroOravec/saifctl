# `docs_old/` → `docspec/` migration tracker

Audit evidence for **NPM-18**. One row per file in `docs_old/`. As each file is migrated (or dropped, or moved to `docs/contributing/`), update the **Status** and the **Successor** column. When every row is `✅`, `docs_old/` can be deleted.

## Buckets

- **MIGRATE** — content belongs in user-facing `docs/` (generated by saifdocs); destination is a `docspec/` entry.
- **CONTRIBUTING** — internal/dev material; destination is `safe-ai-factory/docs/contributing/<file>.md` (handwritten, NOT under saifdocs control). Updated/cleaned when moved.
- **DROP** — superseded, contradictory, or no remaining value. Deleted outright. Reason given.
- **SCHEMA-CHECK** — content doesn't obviously fit Diátaxis quadrants; flag for reshape vs. saifdocs escape-hatch decision when migrated.

## Status

- 🟠 pending
- 🔄 in progress (content extracted, docspec entry being authored)
- ✅ migrated (docspec entry exists OR moved/dropped per bucket)
- ⚠️ blocked / needs decision
