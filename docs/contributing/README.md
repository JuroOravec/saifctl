# Contributing — internal docs

This directory holds **handwritten, internal-facing** documentation for saifctl developers. It is **not** generated by saifdocs; the rest of `docs/` is.

## Why it lives here

Per DOC-09 (release-readiness), `docs/` is the single doc tree. To keep handwritten internals next to generated user-facing pages without losing them on `saifdocs clear`, saifdocs was made manifest-aware (SDR-10): `clear` only deletes paths it tracks in `docspec/.manifest.json`. Anything under `docs/contributing/` is invisible to saifdocs and survives regen.

## Layout

- `docs/contributing/*.md` — current internal docs (CLI architecture, agent-adding workflow, logging conventions, infra notes, etc.).
- `docs/contributing/architecture-history/` — historical SWF v0 design docs preserved as background context. **Most are out of date** and need per-file review — this is intentional kept material, not current truth.
