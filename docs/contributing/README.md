## Day-to-day dev loop

Standard cycle:

```bash
pnpm install                  # once
pnpm run check                # lint + typecheck + tests; what CI runs
pnpm run test -- --watch      # red-green inner loop
```

`pnpm run check` is the same script CI uses, so passing it locally is a strong signal.

## Where to put new docs

- **End-user docs** (concepts, references, how-tos, tutorials) → `docspec/` entry, generated by saifdocs into `docs/`. Don't write user-facing docs as `.md` files in this directory — they'll be invisible to the saifdocs pipeline and drift.
- **Internal docs** (architecture, dev-loop, conventions, debugging hooks) → here. One topic per file.
- **Spec or feature-specific notes** → `saifctl/features/<feature>/`.

## Open contributions

External contributions welcome — see the top-level [`CONTRIBUTING.md`](../../CONTRIBUTING.md) for the public-facing workflow (fork, branch, PR, review). This directory is the *deeper* reference once you're past first-PR onboarding.
